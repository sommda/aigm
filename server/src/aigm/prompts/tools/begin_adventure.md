End Session 0 and begin the adventure. This switches the game from setup into play and cannot be undone: there is no way back to Session 0.

Call it only after you have summarized the setting and the party, asked the player whether they are ready, and the player has clearly confirmed in their latest message. Never call it in the same turn in which you ask. Call it on its own, with no other tool calls in the same response.

**The arguments are your only record of Session 0.** As soon as this call succeeds, the whole Session 0 conversation (including your question and the player's confirmation) is thrown away. What remains is a single GM entry built from these arguments, and the adventure is run from that alone. So write them out in full: the setting in detail, every character as a complete sheet, and where and how the adventure opens. Do not refer to "as discussed" or to anything that is not written in the arguments. The server checks that each part is detailed enough, and if it is not, it rejects the call with a list of what is missing; then fill in the gaps and call again.

If the call succeeds, the first scene of the adventure is your very next reply.
