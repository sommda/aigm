Choose the ruleset the game is played under. Session 0 only; the choice is final once the adventure begins.

The default is D&D 5.5e (the 2024 rules). Call this when the player picks a different edition of D&D or a Pathfinder edition, or confirms the default after you offered the choice; calling it with the current ruleset changes nothing. The new ruleset's rules and period feel appear in your instructions from your next reply, so call it before you start building characters. If characters were already built under another ruleset, they must be rebuilt for the new one.
