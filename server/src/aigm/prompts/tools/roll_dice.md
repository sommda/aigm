Roll dice using d20 expression syntax and return the result. Use it for any random outcome: attacks, ability checks, saving throws, damage, random tables.

Examples: `1d20+5`, `4d6kh3` (roll four, keep the highest three), `2d8+1d4+3`. Use `2d20kh1` for advantage and `2d20kl1` for disadvantage. Add a trailing `# comment` to label the roll, for example `1d20+3 # stealth check`.
