## Ruleset: D&D 4th Edition

Use the 4th Edition rules (Player's Handbook, Dungeon Master's Guide, Monster Manual, 2008) from memory. Levels run 1-30, in three tiers: Heroic (1-10), Paragon (11-20) and Epic (21-30). The game is built around tactical combat, with balanced roles and powers, and a skill-challenge system for non-combat scenes.

### Characters

- **Abilities:** Strength, Constitution, Dexterity, Intelligence, Wisdom, Charisma. Use the standard array (16, 14, 13, 12, 11, 10), a point buy (22 points) or `4d6kh3`. Modifier = (score - 10) / 2, rounded down. The class and race recommend scores.
- **Races:** Human, Dwarf, Eladrin, Elf, Half-elf, Halfling, Dragonborn, Tiefling (and more from later books), each with ability bonuses and racial powers.
- **Classes and roles:** Defender (fighter, paladin), Striker (ranger, rogue, warlock), Controller (wizard), Leader (cleric, warlord). Each has at-will, encounter and daily powers (and utility powers), chosen at creation and level-up.
- **Skills:** trained skills get +5; every character adds half their level to all checks and attacks. Rituals (such as Raise Dead) are a separate, ritual-casting subsystem.
- **Hit points:** fixed by class (a base plus Constitution score at 1st level) and a fixed amount per level. **Healing surges** (a number by class) can be spent in a short rest or by a healing power, recovering a quarter of the character's maximum HP.
- **Defenses:** Armor Class, Fortitude, Reflex and Will, all ascending: an attack roll targets one of them.

### Play

- **Attack:** `1d20` + ability modifier + half level + proficiency/enhancement vs the target's relevant defense. Natural 20 is a critical hit (maximum damage). Powers say what ability, defense and damage they use.
- **Actions:** each turn, a standard, a move and a minor action; immediate and opportunity actions are reactions. **Action points** grant an extra action (one after each milestone of two encounters). Second wind (once per encounter) heals a surge.
- **Initiative:** `1d20` + Dexterity modifier + half level, in descending order. Combat is on a square grid, but convert squares to zones and rough distances.
- **Death:** at 0 or fewer HP a character is dying: a death save (`1d20`, 10 or higher succeeds) each turn; three failures kill. Reaching the negative of their bloodied value (half HP) is death. "Bloodied" (half HP) is a combat state many powers use.
- **Rests:** a short rest (5 minutes) lets you use healing surges and recovers encounter powers; an extended rest (6 hours) restores HP, surges and daily powers.
- **Skill challenges:** a non-combat scene resolved by a number of successes (usually 4-12) before three failures, with each player's skill checks counting. Run these narratively: describe the obstacles, let the players pick skills, and tally successes.
- **Advancement:** XP from monsters and quests; milestone leveling is fine. Magic items are expected at set levels, and the wealth by level table applies.
